# up-im-cms-mcp

MCP-сервер для управления сайтами на up-im CMS из Claude Code: разделы, элементы, подборки, CSV-импорт/экспорт, история изменений, заявки и заказы. Один сервер на все сайты — домен указывается в каждом запросе.

## Установка

Нужен Node.js 20+ и [Claude Code](https://claude.com/claude-code). Сборка не требуется.

```sh
npm install -g https://github.com/Oreen/up-im-cms-mcp/tarball/main
claude mcp add -s user up-im-cms -- up-im-cms-mcp
```

Windows — те же две команды в PowerShell.

Обновление:

```sh
npm install -g https://github.com/Oreen/up-im-cms-mcp/tarball/main
```

Удаление:

```sh
claude mcp remove up-im-cms -s user
npm uninstall -g up-im-cms-mcp
```

## Первый запуск

В Claude Code напиши, например: «Подключи сайт example.ru». Агент вызовет `login` — в браузере откроется страница входа, введи логин и пароль от админки сайта. Пароль нигде не сохраняется; токены доступа хранятся в `~/.config/up-im-mcp/` (Windows: `%APPDATA%\up-im-mcp\`) и обновляются автоматически.

Подключить можно любое количество сайтов — список и статус авторизации показывает `projects`.

## Что умеет

- **Разделы**: дерево, просмотр, создание/правка (включая параметры раздела, SEO, картинку), перенос, удаление, экспорт/импорт структуры в CSV.
- **Элементы**: списки с фильтрами, просмотр, создание/правка любых полей (текст, HTML, даты, справочники, файлы и картинки по пути или URL), копирование, перенос, удаление, экспорт/импорт CSV.
- **Подборки** (виртуальные подразделы): список, создание/правка, копирование, удаление, импорт CSV.
- **Только чтение**: история изменений с поиском, пользователи, заявки с форм, заказы.

При правке передаются только изменяемые поля — остальные данные и файлы сохраняются. После сохранения агент получает ссылку на страницу сайта для проверки.

Примеры запросов:

- «Покажи разделы сайта example.ru»
- «В разделе Новости создай статью с заголовком … и текстом …, картинка — /Users/me/photo.jpg»
- «Выгрузи товары раздела 120 в CSV, я поправлю цены, потом загрузи обратно»
- «Кто и что менял на сайте вчера?»
